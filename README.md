# Bridge Simulator

Build a Star Trek-inspired bridge using existing hardware you likely already have.

## System Overview

- **Console Stations**: Tablets or small computers with touchscreens
- **Game Server**: Any desktop PC or laptop for coordination
- **Effects**: LED strips, existing speakers, TV/projector you already own
- **Network**: Your home network connects everything

## What You Need

**For each console station**:

- Tablet (Android/iPad) OR Raspberry Pi + small monitor
- Small speaker or headphones for local audio
- Stand or mount (tablet stand, simple desk setup)

**Central coordination**:

- Desktop PC, laptop, or server (runs the bridge software)
- TV or projector (for main bridge display)
- Speakers (existing stereo system works fine)
- LED strips (optional for lighting effects)

## How It Works

All devices connect to your local network. The game server runs bridge coordination software and provides a neat frontend to access different station (helm, tactical, science, etc.). Environmental effects like lighting and audio are controlled centrally.
